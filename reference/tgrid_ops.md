# Operations with tgrid objects

Operations with tgrid objects

## Usage

``` r
# S4 method for class 'tgrid'
c(x, ..., recursive = FALSE)

# S4 method for class 'tgrids'
c(x, ..., recursive = FALSE)

# S4 method for class 'tgrid,numeric'
e1 + e2

# S4 method for class 'tgrid,numeric'
e1 * e2

# S4 method for class 'tgrids,numeric'
e1 + e2

# S4 method for class 'tgrids,numeric'
e1 * e2
```

## Arguments

- x:

  a tgrid object.

- ...:

  additional tgrid objects.

- recursive:

  not used.

- e1:

  tgrid or tgrids object

- e2:

  numeric value
