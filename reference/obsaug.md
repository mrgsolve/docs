# Augment observations in the simulated output

Augment observations in the simulated output

## Usage

``` r
obsaug(x, value = TRUE, ...)
```

## Arguments

- x:

  model object

- value:

  the value for `obsaug`

- ...:

  passed along There is also a `obsaug` argument to
  [`mrgsim`](https://mrgsolve.org/docs/reference/mrgsim.md) that can be
  set to accomplish the same thing as a call to `obsaug` in the
  pipeline.
