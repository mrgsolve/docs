# Scrape options and pass to function

Scrape options and pass to function

## Usage

``` r
scrape_and_call(x, env, pass, ...)
```

## Arguments

- x:

  data

- env:

  parse environment

- pass:

  function to call

- ...:

  arguments passed to
  [`scrape_opts`](https://mrgsolve.org/docs/reference/scrape_opts.md)

## Details

Attributes of `x` are also scraped and merged with options.
