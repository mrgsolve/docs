# Collect only observation records in the simulated output

Collect only observation records in the simulated output

## Usage

``` r
obsonly(x, value = TRUE, ...)
```

## Arguments

- x:

  model object.

- value:

  use \`TRUE\` to collect and return observation records only.

- ...:

  not used.

## Details

There is also an \`obsonly\` argument to \[mrgsim()\] that can be set to
accomplish the same thing as a call to \`obsonly()\` in the pipeline.
